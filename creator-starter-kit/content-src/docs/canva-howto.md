# How to use the templates with Canva

## What you receive

For each template you get three files (Starter includes 10 templates, higher tiers include all 50):

- **svg/** — the complete design as a vector file with live text. Open it in Figma, Affinity, Illustrator or Inkscape to edit text and colours directly.
- **backgrounds/** — the same design without text, as an SVG. Upload it to Canva and add your own editable text on top using the specs in the catalogue.
- **png/** — a preview image (1080 px wide) for reference.

> **Important:** these are original designs supplied as vector and image files. They are not Canva share links, and we do not claim they are native Canva templates. Canva can import SVG and PNG files as images, but it does not convert them into editable Canva elements automatically. The catalogue lists exact sizes, colours, fonts and text positions so you can rebuild any layout in a few minutes.

## Option A · Edit directly in a vector editor

1. Open the file from *svg/* in Figma (drag it into a frame), Affinity or Inkscape.
2. Install the font **Inter** (free, Google Fonts). Serif designs use **Playfair Display** (free, Google Fonts).
3. Edit the text and colours, then export as PNG or JPG at 1080 px wide.

## Option B · Use Canva

1. In Canva, create a design with the custom size shown in the catalogue (for example 1080 × 1350 px).
2. Open *Uploads* and upload the file from *backgrounds/*. Drag it into the design and resize to fill the page.
3. Add text boxes. Use the text list on the template's catalogue page for font, size, weight, colour and position. Inter and Playfair Display are available in Canva.
4. Group everything and save the design as your own template (Canva account required; the template-saving feature depends on your plan).

## Tips

- Change the accent colour once and reuse it everywhere to match your brand.
- Keep important text 80 px away from the edges for safe margins.
- Replace the sample handle (@yourhandle) with your own.
- Check that text has enough contrast with the background after changing colours.

## Canva Pro

You don't need Canva Pro for the steps above. Canva Pro features (such as Brand Kit and Magic Resize) can save time but are optional. Free plans' features and limits can change; check Canva's current pricing page.
